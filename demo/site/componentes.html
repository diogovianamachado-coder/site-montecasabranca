Os componentes que o design encaixa nas páginas

Cada bloco abaixo é um encaixe do kit (data-base="…") montado com dados de exemplo e só com o CSS estrutural: sem cores, sem tipos, sem espaços de desenho. É isto que o ChatGPT veste com o CSS do site. O contrato completo está em demo/base/CONTRATO.md; os dados têm a forma exata das portas da app (contrato_portas_v1.md), por isso trocar o exemplo pela app é trocar um endereço.

Tudo o que aqui aparece é exemplo identificado: a ocupação é inventada, a conta é a tarifa do FACTOS.md, o tempo é o Open-Meteo ao vivo (ou uma semana de exemplo sem rede) e o pedido não é enviado a lado nenhum.

Exemplo estático do simulador (substituído pelo kit).

A conta é a da app: tarifa privada 2026/2027, limpeza do ano uma por estadia, mínimo 2 noites, verão de sábado a sábado (7 noites), mensal de novembro a março, pôr do sol ao domingo calculado no browser. Experimentem 24/07/2027 → 31/07/2027 (verão) e 05/01/2027 → 02/02/2027 (mensal).
