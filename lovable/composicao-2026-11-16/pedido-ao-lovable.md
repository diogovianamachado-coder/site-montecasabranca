REGRAS TÉCNICAS (a composição vai ser passada para PHP + CSS + JavaScript simples e tem de correr bem no Safari do iPhone)
- Movimento só com CSS (transform, opacity, transition, @keyframes, scroll-snap) e IntersectionObserver. Sem bibliotecas de animação. Sem JavaScript a mexer no scroll a cada frame (foi isso que prendeu a página).
- Sequências de fotografias: rolagem horizontal nativa com scroll-snap (o dedo manda) e largura e altura explícitas em cada caixa. Nada de larguras tiradas de aspect-ratio dentro de flex ou grid: no Safari do iPhone deixou caixas meio vazias. Se avançarem sozinhas, que seja um passo de cada vez de poucos em poucos segundos, que pare quando o dedo toca e com «reduzir movimento» ligado.
- Poucos backdrop-filter. Campos de data com min-width: 0 (no iPhone saíam do ecrã).
- Ao escolher um destino no menu, o menu fecha e a página vai para lá sem prender. Com o painel aberto, o fundo não rola.
- Leitura ótima a 390 px e a 1280 px, sem rolagem horizontal. Todo o texto no HTML.
